## Browser Overlay Extension

The manual decision overlay is in this repo folder:

browser-extension/

Install steps:

1. Download this repository as a ZIP from GitHub.
2. Extract the ZIP.
3. Open Chrome or Brave.
4. Go to chrome://extensions/
5. Enable Developer Mode.
6. Click Load unpacked.
7. Select the extracted browser-extension/ folder.

Supported exchanges:

- Coinbase Advanced Trade
- Crypto.com Exchange overlay injection support

The extension is manual decision support only. It does not place trades, click exchange buttons, read credentials, or access account balances.

## Scope

This GitHub Pages app is a public-market-data dashboard with paper-mode tracking. It does not submit exchange orders from the browser.
