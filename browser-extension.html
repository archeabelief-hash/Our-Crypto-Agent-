Install Steps

1. Download coinbase_sniper_overlay_extension.zip
2. Unzip it
3. Open chrome://extensions
4. Turn on Developer mode
5. Click Load unpacked
6. Select the unzipped extension folder
7. Open Coinbase

Safety

The extension overlays manual signals only. It does not read passwords, API keys, balances, cookies, or place orders. It can optionally send public signal data to your local bridge if enabled in settings.
